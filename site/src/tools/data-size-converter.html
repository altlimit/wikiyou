What is a data size converter?

A data size converter expresses the same quantity in different units of digital information. One byte (B) contains eight bits. Decimal units such as kilobytes (kB, often written KB) and megabytes (MB) use powers of 1,000. Binary units such as kibibytes (KiB) and mebibytes (MiB) use powers of 1,024.

How to use this converter

Enter a quantity and select its current unit and the unit to convert to. The result updates immediately and displays the exact decimal value in the selected destination unit.

The formula

Multiply the amount by the number of bits in its source unit, then divide by the number of bits in the destination unit. A gigabyte is 1,000³ bytes and a gibibyte is 1,024³ bytes.

Worked example

To convert 1.5 MiB to KiB, multiply 1.5 by 1,024² bytes per MiB and divide by 1,024 bytes per KiB. The result is 1,536 KiB.

Input limits

Zero converts to zero. The calculator accepts up to 18 digits before the decimal point and 12 after it. Negative amounts, exponent notation and thousands separators are invalid. Fractional results describe quantities in the selected unit, including quantities smaller than one byte.
