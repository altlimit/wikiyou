Overview

Mozilla Firefox, usually called simply Firefox, is a free and open-source web browser developed by the Mozilla Foundation and its subsidiary, the Mozilla Corporation. It is available for Windows, macOS and Linux on the desktop, and for Android and iOS on mobile devices. Its source code is published under the Mozilla Public License.

Firefox renders web pages with Gecko, a browser engine developed by Mozilla. This makes it one of the few major browsers not built on Chromium’s Blink engine or Apple’s WebKit, and it is often cited for that reason as a source of independence in how web standards are implemented.

History

Firefox descends from Netscape Navigator. In 1998 Netscape released the source code of its browser and founded the Mozilla project to develop it in the open; that work produced the Mozilla Application Suite, which combined a browser with an email client, an HTML editor and other components.

Firefox began in 2002 as an experimental branch of that project, started by Mozilla developers including Dave Hyatt and Blake Ross, with the aim of producing a smaller, faster, standalone browser. It was first released under the name Phoenix, renamed Firebird after a trademark conflict, and renamed again to Firefox in 2004 because the Firebird name was already used by an open-source database project. Firefox 1.0 was released in November 2004.

The Mozilla Foundation, a non-profit organization, was established in 2003 to oversee the Mozilla project. In 2005 it created the Mozilla Corporation, a wholly owned taxable subsidiary, to handle the development and distribution of Firefox.

Development

In 2011 Firefox moved from infrequent major releases to a rapid release cycle, publishing a new numbered version every few weeks. Alongside the main release, Mozilla offers beta and nightly builds for testing, and an Extended Support Release (ESR) channel that receives security fixes over a longer period, intended for organizations that cannot update frequently.

In 2017 Firefox 57, branded Firefox Quantum, introduced a substantial reworking of the browser’s engine. It incorporated components written in Rust, a programming language that originated at Mozilla, including a parallel CSS style engine developed in Mozilla’s experimental Servo browser engine project. The same release dropped support for Firefox’s older extension system.

On iOS, Firefox uses Apple’s WebKit engine rather than Gecko, because Apple’s platform rules have required third-party browsers to do so.

Features

  • Extensions — Since Firefox 57, add-ons are built on the WebExtensions API, which is largely compatible with the extension model used by Chromium-based browsers. Mozilla distributes them through its add-ons site.
  • Privacy protections — Firefox includes private browsing and Enhanced Tracking Protection, which blocks many known third-party trackers by default.
  • Sync — With a Mozilla account, bookmarks, history, passwords and open tabs can be synchronized between devices.
  • Developer tools — Firefox ships with built-in tools for inspecting and debugging web pages, including an element inspector, a JavaScript console and debugger, and a network monitor.
