Overview

Python is a high-level, general-purpose programming language. It is dynamically typed, garbage-collected and interpreted, and supports several programming styles, including procedural, object-oriented and functional programming. Its design emphasizes code readability: blocks of code are delimited by indentation rather than by braces or keywords.

Python is free and open-source software, distributed under the Python Software Foundation License. It is used widely for scripting and automation, web development, scientific computing, data analysis, machine learning and teaching, and it is supported on all major operating systems.

History

Python was created by Guido van Rossum, who began working on it in the late 1980s at Centrum Wiskunde & Informatica (CWI) in the Netherlands as a successor to the ABC programming language. He released the first public version, 0.9.0, in 1991. The name comes from the British comedy series Monty Python’s Flying Circus, not from the snake.

Python 2.0 was released in 2000. Python 3.0, released in 2008, was a major revision that was deliberately not fully backward-compatible with Python 2, so that long-standing design problems could be corrected. The two lines were maintained in parallel for many years; Python 2 reached its end of life on 1 January 2020, after which it no longer received updates.

Van Rossum led the project for most of its history and held the informal title of “Benevolent Dictator For Life”. He stepped down from that role in 2018, and leadership of the language passed to a steering council elected by Python’s core developers.

Governance

The Python Software Foundation (PSF), a non-profit organization founded in 2001, holds the intellectual property rights to Python, manages its trademarks, and supports the community around it. Changes to the language are proposed and discussed through Python Enhancement Proposals (PEPs), design documents that describe a new feature or process. PEP 8, for example, is the style guide for Python code, and PEP 20, “The Zen of Python”, sets out the language’s guiding principles.

Implementations and ecosystem

  • CPython — The reference implementation, written in C and maintained by the core developers. When people refer to Python without qualification, they usually mean CPython.
  • Other implementations — Alternatives include PyPy, which uses a just-in-time compiler, and MicroPython, a reduced implementation for microcontrollers.
  • Standard library — Python ships with a large standard library, a design approach often summarized as “batteries included”.
  • Packages — Third-party packages are published on the Python Package Index (PyPI) and are installed with the pip package installer.
